# Accessible portfolio

Multi-page portfolio in semantic HTML5 targeting WCAG 2.2 AA and 100 on Lighthouse Accessibility and SEO.

## Before publishing
1. Replace `prathamshinde234` and `Asha Raman` across the HTML files, `robots.txt` and `sitemap.xml`.
2. Replace `your-form-id` in `contact.html` with your Formspree form ID.
3. Replace placeholder copy, portrait and projects.

## Audit
Serve the folder (`npx serve .`), then run Lighthouse in Chrome DevTools. Also test with the Tab key and a screen reader.
